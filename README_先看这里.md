# 灵犀记忆 MCP 使用入口

当前推荐从公开源码自动安装，默认使用通用 MCP 配置。请先读 [README.md](README.md) 和 [AGENT-INSTALL.md](AGENT-INSTALL.md)。不要求安装任何指定品牌的 Agent，也不需要 GitHub 登录。

源码目录不是预装运行环境的便携包。使用 Install-Agent.ps1 自动准备程序与依赖；不要直接运行依赖 vendor 的旧安装.cmd。原离线打包脚本保留作开发维护用途，不在公开仓库分发个人运行环境或历史安装包。

同机先检查既有安装及登录；未登录才由本人正常登录灵犀。是否保存本机登录由本人选择。普通聊天不自动保存记忆，提交和读回核对遵循配套 Skill 的规则。
